# 🏎️ 타자팡: 방언 대모험 (TajaPang Dialect)

> **혼자서 즐기는 우리말 타자 게임** — 배움팡 친구들과 타자 달리기를 하고, 방언 보스와 타자로 겨룹니다.

---

## 🌟 주요 특징

1. **싱글 전용, 서버·계정 없음**
   - 게임 서버나 데이터베이스, 로그인 없이 브라우저 안에서만 동작합니다.
   - 플레이 기록은 학생 브라우저의 로컬스토리지에만 보관합니다(최근 50개).
2. **개인 연습 (배움팡 달리기)**
   - 초급 🐢 / 중급 🐇 / 고급 🐆 AI 팡 친구를 최대 2명까지 불러 함께 달립니다(나까지 3명, 트랙 3줄에 한 명씩 고정). 친구마다 나와 겹치지 않는 배움팡이 나오고, 속도는 대기실에서 조절합니다. 문장부호 제외는 기본으로 켜져 있습니다.
   - 칠판형 타자 영역, 셋·둘·하나 카운트다운, 실시간 순위, 운동장 트랙 3줄 줌인(콩콩 뛰는 배움팡)과 미니맵, 결과 리포트와 AI 타이핑 진단을 제공합니다.
   - 영문 자판으로 치면 2벌식 한글로 자동 변환하고 [한/영] 안내를 띄웁니다.
3. **방언 타자 대결 (타자 가위바위보)**
   - 제주 → 충청 → 전라 → 경상 → 강원 보스를 차례로 물리치면 다음 보스가 열립니다. 해금·클리어 기록은 로컬스토리지에 저장합니다.
   - 가위·바위·보 카드의 짧은 방언 문장 중 하나를 제한시간 안에 쳐서 내고, "가위! 바위! 보!" 후 보스와 동시에 공개합니다.
   - 승리 피해는 남은 시간·무결점 보너스로 커지고, 비기면 더 빨리 친 쪽이 작은 피해를 줍니다. 무결점 3회로 필살기 문장이 등장하고, 필살기 피해는 보스 체력의 1/3입니다(제주 40 ~ 강원 55). 보스 체력 120~160, 학생 체력 120으로 한 판이 10라운드 안팎이 되도록 맞췄습니다.
   - 공개 후 카드 문장의 표준어 풀이를 보여 주고, 보스 대사의 뜻은 그 보스를 이긴 뒤에 공개합니다. 보스 선택 화면 위쪽 [대결 설정] 팝업에서 방패 규칙(기본 꺼짐), 띄어쓰기 기호 표시, 카드 뜻 미리 보기, 여유 모드(제한시간 +5초, 이겨도 레벨 그대로), 연출 빠르게, 효과음(Web Audio)을 켜고 끌 수 있습니다. 규칙은 보스 선택 화면 위쪽의 [규칙 보기] 팝업으로 보며, 처음 들어오면 한 번 자동으로 열립니다.
   - 보스 가상 타수는 개인 연습 팡 친구와 같은 방식(리듬 흔들림·머뭇거림)으로 계산하며, 같은 보스를 이길 때마다 다음 도전에서 레벨이 올라 +50타씩 빨라집니다(최고 레벨 5).
   - 숨겨진 보스 **표준어 광장의 표준어 박사**(`HIDDEN_BOSS`): 다섯 지역 보스를 모두 이기면 보스 선택 화면 오른쪽 위 상자가 반짝이는 도전 버튼으로 바뀝니다. 다섯 지역 카드(문장부호가 없고 12자 이하인 표준어 풀이, 89장)에서 뽑은 방언 카드를 보고 **표준어 풀이를 칩니다**. 체력 170·공격 23·제한시간 15초·가상 타수 200타, 필살기 55. 지역 보스 기록을 하나라도 지우면 다시 잠기고, 표준어 박사 기록과 레벨은 남습니다. 서울·경기를 지역 보스로 두지 않고 '모두가 함께 쓰는 공통말' 무대로 만들어, 방언과 표준어 사이에 위아래가 생기지 않게 했습니다.
   - 방언 데이터(`app/dialect/data/dialectBosses.ts`) 검토 현황
     - 제주: [국립국어원 우리말샘](https://opendict.korean.go.kr)과 [제주어모바일사전(제주어교육연구소)](http://jejudic.kr)으로 핵심 낱말 확인 완료 (어미 '-우다'·'-게'는 [국립국어원 지역어 종합 정보](https://dialect.korean.go.kr/dialect/) 구술발화 자료)
     - 충청: [국립국어원 우리말샘](https://opendict.korean.go.kr)(충청 지역 표시)과 [국립국어원 지역어 종합 정보](https://dialect.korean.go.kr/dialect/)('-유'·'-쥬' 어미 등 구술발화 자료)로 확인 완료, '냅두다'·'욕보다'는 [국립국어원 온라인가나다](https://korean.go.kr/front/onlineQna/onlineQnaList.do?mn_id=216) 답변 참고
     - 전라: [국립국어원 우리말샘](https://opendict.korean.go.kr)과 [국립국어원 지역어 종합 정보](https://dialect.korean.go.kr/dialect/)(어휘·구술발화 조사 자료, 문학 속 지역어)로 확인 완료
     - 경상: [국립국어원 우리말샘](https://opendict.korean.go.kr)과 [국립국어원 지역어 종합 정보](https://dialect.korean.go.kr/dialect/)로 확인 완료. '욕보다'는 '수고하다'의 경상 방언이지만 표준어 '욕보다'의 뜻을 고려해 쓰지 않음([온라인가나다 답변](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=334122) 참고)
     - 강원: [국립국어원 우리말샘](https://opendict.korean.go.kr)과 [국립국어원 지역어 종합 정보](https://dialect.korean.go.kr/dialect/)로 확인 완료 ('-드래요'는 강원 구술발화 자료의 간접 근거)
4. **지역별 방언 꾸러미 (개인 연습)**
   - 제주·충청·전라·경상·강원 5개 꾸러미. 방언 타자 대결의 카드·필살 문장·보스 대사에 연습용 추가 문장(`practiceExtras`)을 더해 지역마다 30문장씩 씁니다(`practiceLinesFor`, 모두 검토 완료).
   - 방언만 치고, 뜻(표준어)은 문장 아래에 작게 보여 줍니다.

## 🚀 실행 방법

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:3000)
npm run build    # 배포용 빌드
npm run lint     # 코드 검사
```

- 배포 시 필요한 환경 변수는 없습니다. Next.js를 지원하는 호스팅(예: Vercel)에 그대로 올리면 됩니다.
- 개발자 도구·우클릭 차단 스크립트는 넣지 않습니다(코드는 어차피 브라우저에 내려가 실제 보호 효과가 없고, 선생님이 문제를 확인할 때 방해가 되어 뺐습니다).
- 스마트폰 접속은 세로·가로 모두 차단되며, 데스크톱·노트북·크롬북 같은 큰 화면에서 사용합니다.
